# Hayatta Kal

A top-down horde survival game. Your crossbow fires on its own; you move, collect gems, level up and pick upgrades while the waves grow.

Built in Godot 4.7 by Claude Code (Opus 5.5). Every model, texture, music track and cutscene was generated with [Higgsfield](https://higgsfield.ai). The in-game text is in Turkish.

## Play

Download the build for your system from [Releases](https://github.com/yusufipk/hayatta-kal/releases/latest) and run it. Nothing to install.

- **Windows:** `HayattaKal.exe`. The file is not code-signed, so SmartScreen may warn you: click "More info", then "Run anyway".
- **Linux:** `chmod +x HayattaKal.x86_64 && ./HayattaKal.x86_64`

Needs a GPU with Vulkan support (or Direct3D 12 on Windows).

## Controls

- **WASD** or **arrow keys:** move (aiming and shooting are automatic)
- **1 / 2 / 3:** pick an upgrade card on level up
- **Space**, **Enter** or **Esc:** skip the intro
- **R:** restart

## Run from source

Open `project.godot` in [Godot 4.7](https://godotengine.org/download) and press F5.
